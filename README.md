## 📌 About The Website

This portfolio is handcrafted from scratch without heavy UI frameworks or third-party template bloat. It is designed to be lightweight, fast, accessible, and easy for recruiters, HR professionals, and technical interviewers to evaluate my profile.

### ✨ Key Features

- **🌓 Dark & Light Mode:** Seamless theme switching with persistent state saved in `localStorage`.
- **📱 Fully Responsive:** Mobile-first layout optimized for smartphones, tablets, laptops, and wide screens.
- **📄 Instant Resume Access:** Direct buttons to **Download Resume** as well as **View Resume** in a new browser tab.
- **🧭 Active ScrollSpy:** Top navigation automatically tracks and highlights the active section as you scroll.
- **💼 Clean Project Cards:** Focused technical cards detailing features and implementation for *Team Collaboration Dashboard* and *Placement Preparation Portal*.
- **🏅 Verified Certifications:** Card-based credentials highlighting courses from CodeChef, Simplilearn, NPTEL, NoviTech, and Trekverse with details modals.
- **✉️ Validated Contact Form:** Client-side validation for Name, Email, Subject, and Message with pre-composed direct email dispatch.
- **⚡ Zero External Dependencies:** Built entirely with semantic HTML5, modern CSS3 (Flexbox & CSS Grid), and Vanilla JavaScript.

## 🚀 How to Run Locally

### Option 1: Using Node.js (Quickest)
1. Clone the repository:
   ```bash
   git clone https://github.com/msrikavya8/portfolio.git
   cd portfolio
   ```
2. Start the local server:
   ```bash
   node serve.js
   ```
3. Open your browser at:
   ```text
   http://localhost:3000/
   ```

### Option 2: Using VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Right-click `index.html` and click **"Open with Live Server"**.
3. The site will open at `http://127.0.0.1:5500/index.html`.

### Option 3: Direct Browser Launch
Simply double-click `index.html` in your file explorer to open it directly in Chrome, Edge, or Firefox.

---

## 🌐 How to Deploy on GitHub Pages

1. Go to your repository on GitHub: `https://github.com/msrikavya8/portfolio`.
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. In 1–2 minutes, your website will be live at:
   ```text
   https://msrikavya8.github.io/portfolio/
   ```
